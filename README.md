# AttendX-Test-Scripts

## Project Description
This repository contains sample Python tests for the
AttendX student attendance application for you.

## Files
- login_test.py: Tests valid login, wrong password,
  and empty login fields.
- attendance_test.py: Tests attendance marking,
  duplicate attendance, and empty student ID.

## Requirements
- Python 3
- Git
- Visual Studio Code

## Run Tests
python login_test.py
python attendance_test.py

## Purpose
Git and GitHub are used to track changes, maintain
version history, and share test scripts among QA engineers.
